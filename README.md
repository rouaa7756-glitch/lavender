# موقع زهور اللافندر🪻

موقع تفاعلي لعشاق زهور اللافندر، يقدم معلومات شاملة عن:
- خصائص اللافندر
- الفوائد الصحية
- معرض صور جميل
- طرق التواصل

## المميزات
- تصميم متجاوب
- ألوان هادئة
- صور عالية الجودة
- سهولة الاستخدام

## التقنيات المستخدمة
- HTML5
- CSS3
- JavaScript
- Font Awesome
